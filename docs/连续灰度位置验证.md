# 连续灰度位置验证（2026-10-25，实验阶段）

目标：保留八路模拟读数中的强弱信息，获得探头之间的位置变化，再评估是否能改善高速循线。已完成静态采样并制作过 T314 转向试验版；因模型出现新增 D 点丢线失败，转向接入已撤回并归档，**没有烧录、没有提速**。当前只保留独立估计器、采样/回放工具及数据。板上仍是 T312；此前四圈 36.081 s 的成绩没有被本次静态采样更新。

## 代码与验证

`Core/Src/gray_position.c` 按各通道白黑参考归一化，扣除小幅底色，检查连续黑色区域。宽区域、分离区域和弱信号返回无效。有效时只用该连续区域及相邻探头计算加权位置，防止远处微弱底色把位置拉向另一端；相邻弱信号仍可提供探头之间的插值。默认 15 mm 间距，支持通道顺序反向和各通道黑白极性。阈值仍为待实车验证的实验参数。

初版全排加权在扫描的某一帧中，把末端黑线计算到了约 +27.83 mm；该帧另一端存在低于激活阈值的底色。加入局部区域限制后，远端底色不再参与位置计算。单元测试覆盖这一实测暴露的问题、相邻探头连续交接、通道顺序/极性、白底/宽线/分离区域和异常标定输入。

`tests/run_tests.py --trial-profile time-trial-arc-step --sanitize` 全部通过，包括新增位置算法及现有 T312 和公共回归。真实扫描通过同一个 C 实现离线回放，使用 ASAN/UBSAN；没有用另一份 Python 公式替代固件算法。生产 CMake、灰度阈值、控制器和速度已恢复原状，板上镜像从未改动。仅二值输入的旧仿真不能验证模拟灰度转向，因此另建下述光学响应敏感性实验。

## 白底完成与转向试验结果

用户确认整排白底后，采到 92 个独立帧、4.952 s，八路中位数为 `[1241,339,317,288,309,539,759,623]`，各路极差为 `[1,0,0,1,0,0,1,4]`。旧扫描参考值在这组独立白底上全部返回 WHITE；将白底中位数与扫描峰值组合后仍全部 WHITE。后者使用了训练数据，不冒充新的独立验证。新参考值回放扫描：119 有效、25 WHITE、428 SPLIT；回放回中组：97/97 有效。

T314 曾实现同一临界区复制模拟/二值帧、帧号与帧龄检查、仅改变弯道反馈、二值过点/定位检查保持、异常/过期回退、切换来源时抑制模拟微分突变。静态与控制器回归通过，但扩展模型没有通过；不能根据编译或旧回归通过就烧录。

模型固定原电机参数，增加假设光学感应半宽 3/6/9 mm，从真实模型位置生成八路模拟量，再调用实际 C 估计器；同时保留原几何二值检测。每种半宽检查相位 0/2/5/7/10/12 ms × 全套/逐圈 D 偏移/逐圈 C 偏移，共 18 组。光学响应是假设，不是实测传递曲线。

## 下一步

白底采样已完成，不需要再次要求用户重做相同摆放。应先定位研究模型中新增 D 点失败的原因，并取得能够支持动态位置精度的证据；不要只根据静态读数更连续就提速或烧录。

后续接入时必须让模拟值与二值状态属于同一帧，保留新帧/丢线/端点及车体覆盖检查。新算法应先在当前速度验证动态转向，再讨论提速；目前不声明已达到四圈 30 s。
