# T317 入弯保持与验证

2026-10-25 实车 CROSS4 完成，用时 **35.667 秒**；4 圈、17 次点事件、fault=0。比 T315 的 36.123 秒快 0.456 秒，比 T312 的 36.081 秒快 0.414 秒，尚未达到 30 秒。此处为一次板载计时结果，不代表重复性或独立场地覆盖验证。

## 本次改动

- 仅在刚进入弧线、上一观测在外侧探头、短暂丢线时，保留已有 P 转向修正，直到原有 180 ms 失线截止时间。旧版在 80 ms 后已经撤掉此修正。
- 仍禁用过时 D 项；成熟弧线、居中误差、没有历史观测均不延长保持；白色仍不能产生点事件，失线停车时间不变。
- 弯速 450→460 mm/s；直线 800、接线 370、轮速上限 1000、直线 PWM 预算 900 均保持。Normal/Cross、1/4 圈及 OLED 操作保持。
- 保留 T315 的板载速度记录。未集成模拟连续位置转向、出弯延迟外推、入线位置投影、提前或延后减速等未通过方案。

## 实车操作

1. 长按 USER 约 1 秒切到 **CROSS**，确认 **LAPS 4**。
2. 两驱动轮轴线中点对准 **A**，车头朝 **B**，前排探头在白底。
3. 拔电脑线，短按并松开 USER，静止等待自动校准后启动。
4. 跑完保持电池供电，接回电脑，不复位、不再次启动。回收时使用 `tools/read_t317.tcl` 和唯一前缀，例如 `build-local/captures/t317-run-01`。

速度记录布局与 T315 相同，可用 `tools/decode_speed_trace.py` 解码；整个四圈成绩仍从原轨迹和 run_at 计算。源码已变更固件魔数，旧 T315 回收脚本会拒绝，不能绕过检查。

分段由稀疏轨迹估算，另有启动后首条记录前的 1 ms。总时长由 run_at=104672 到首条完成记录计算，含最终停止确认。8 次出弯均首次候选被接受；灰度超时、错误、意外字节为 0，左右峰值 PWM 均为 901/1000，输出饱和计数为 0。速度窗口记录 95/87 条，无丢弃或裁切；最大记录开销 4952 周期，按 72 MHz 约 68.8 μs。

本次编码器估算直线均速 661.6 mm/s，弧线均速 444.9 mm/s。若弧线和停止确认耗时不变，仅靠直线达到 30 秒需要直线均速约 1064.7 mm/s，超过当前 1000 mm/s 轮速目标上限；因此还需改善弯道与接线。该预算假定路径不变、没有轮胎打滑修正，不是可实现速度预测。
