# H题固件软件验证记录

日期：2026-10-23。目标为 WHEELTEC C10B / STM32F103RCT6。基于仓库提交 `022b896b728c7318f210a88bbd038eb5b856db7d`，实现四项 H 题课程路线。

交付固件使用用户确认的 65 mm 轮径，保留待测计数和尺寸为 0，`CAR_CALIBRATION_CONFIRMED=0`，因此可以查看传感器诊断，但不会启动电机任务。填写实测参数后须重新编译。

## ARM 编译

macOS arm64，官方 Arm GNU Toolchain 14.3.rel1，GCC 14.3.1。工具链归档 SHA256 与官方校验值一致：

`30f4d08b219190a37cded6aa796f4549504902c53cfc3c7e044a8490b6eba1f7`

使用 `tools/build_firmware.py` 编译，源码列表从 CMake 文件提取。Debug / Release 均编译及链接成功，没有编译警告，生成 ELF / HEX / BIN。

| 配置 | Flash / BIN | RAM 含堆栈预留 | 初始 SP |
| --- | --- | --- | --- |
| Debug | 30188 B / 256 KB | 2432 B / 48 KB | 0x2000C000 |
| Release | 21916 B / 256 KB | 2432 B / 48 KB | 0x2000C000 |

`tools/verify_firmware.py` 已核对 BIN 容量、RCT6 初始栈、Thumb 复位入口、UART4 向量与 ELF 符号一致，并核对 HEX 记录校验和与 BIN 数据。新文件在 `build-local/`，仓库原有 `build/` 为历史产物。

## 主机测试

使用 Apple Clang 执行 `python3 tests/run_tests.py --sanitize`，启用 AddressSanitizer 和 UndefinedBehaviorSanitizer，所有测试通过。

- 未标定禁止启动；参数非有限值拒绝；控制器零命令和异常输入输出零；PI 饱和限制。
- USER 消抖、短按启动、长按选任务、行驶按下停止、松开不重启、上电按住不启动、使能关闭及恢复。
- 计划中的白底行驶不触发丢线；全黑及远离端点的黑线不推进任务；重复旧帧不累计确认次数。
- 灰度或 IMU 故障锁定停车，通信恢复不自动启动；控制周期超时及堵转停车。
- 编码器 16 位正反向回绕、32 位时间回绕、静止零偏校准、角速度积分、动态校准拒绝和采样失败失效。
- UART 全部 256 个状态字节、四种极性／顺序组合、超时、迟到、额外字节、模拟量长帧拒绝、UART 错误和时间回绕。
- 板级引脚所有权、TIM4/TIM8、PA15、SWD 保留、型号、链接空间和 UART4 向量审计。

## 路线模拟

`tests/sim_course.c` 独立建立差速小车运动、轮速一阶响应和两条半圆黑线的几何模型。控制器只能得到模拟的编码器、陀螺仪和八路灰度；测试没有直接安排它的路段切换。

模拟尺寸为轮距 120 mm、探头前置 70 mm、车体前后各 125 mm、半宽 75 mm；每轮计数 1560 只作为测试配置，不是 MG513X 的确认参数。模型在每个端点提示时核对真实模拟车体是否覆盖该点，检查弧线状态下车体与指定圆弧是否相交，以及最终状态、事件数和圈数。

| 任务 | 对称电机无漂移 | 左右电机系数 0.95 / 1.05，加 0.001 rad/s 剩余航向漂移 | 事件数 |
| --- | --- | --- | --- |
| 1 | 约 4.54 s | 约 4.54 s | 2，启动 A 与停车 B |
| 2 | 约 24.62 s | 约 24.38 s | 5 |
| 3 | 约 29.42 s | 约 29.50 s | 5 |
| 4 | 约 117.23 s | 约 117.8 s | 17，四圈 |

时间是模拟结果，二值传感阈值附近的浮点差异可造成小幅变化，不代表实车成绩。模拟另外注入弧线通信中断、持续全白、单轮编码器停滞、控制超时，均正确停车并锁定故障。

模拟中发现并修正了一个系统误差：前置探头离开半圆时，车身航向不等于端点切线。当前按前置距离和圆弧半径估计车身角度，进行有限比例的端点修正，四圈模型中的航向漂移不再导致漏掉端点。
