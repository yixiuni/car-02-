# T321-C1：C 点入弯覆盖余量

2026-10-25。T321-UART 最新实车记录四圈 30.703 秒、无故障，但用户报告 C 点偶尔在车身右侧漏盖约 1～2 cm。程序估算的四次 C 过点侧向余量均超过 52 mm，与用户观察不一致；不能把里程估算当作真实车体覆盖。第二圈 C 的估算车头余量仅 5.22 mm。记录见 [实车数据](data/t321-uart-cross-four-run-01.json)。

T321-C1 只收紧 CROSS 的 C 入弯确认：C 点在估算车头内至少 15 mm，右侧线误差不超过 7.5 mm（原 22.5 mm），才结束接线并切入弯道。确认前保留原灰度预转向和 370 mm/s 接线速度；白底、全黑、旧帧不能充当新的有效过点观测。左侧线条件、D 点、NORMAL、瞄准点、各段速度上限和灰度标定不变，保留 T321-UART 连续帧修复。此改动是覆盖余量假设，不能直接保证真实右侧漏盖消失；接线阶段可能稍长，速度目标未提高。

先比较 C 瞄准点 15/0/-10/-20 mm，27 组交叉/接线模型分别通过 27/24/13/9，未部署这些偏移方案。随后比较 C 车头余量和右侧灰度门限，所选 15 mm / 7.5 mm 组合通过初筛。正式代码的 225 组模型通过 224 组；唯一失败仍是原有 NORMAL 弱电机 gain1.5、灰度 phase14 的 D 覆盖，CROSS-full/C-offset/D-offset 各 45/45。ASAN/UBSAN 回归通过，1124 条 PASS；新增边界测试验证车头余量、右侧线门限、旧帧/白底/全黑排除及 D/NORMAL 不受新门限影响。

烧录前保留完整 RAM、旧镜像和本轮轨迹；新 BIN/HEX 验证和完整回读一致。待机两次灰度有效帧 419→503、错误/超时 0、初始同步丢弃 8 字节后未增加、全部就绪标志正常、PWM/CCR 为 0。默认 NORMAL / 1 圈，未远程启动。实车验证待完成。
