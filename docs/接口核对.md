## 板载电机接口

| 通道 / 接口 | 针号 | 电路连接 |
| --- | --- | --- |
| B / U5 / CN2 | 1、6 | BO1、BO2 电机两端 |
| B / CN2 | 2、5 | GND、编码器 5V |
| B / CN2 | 3、4 | PC6、PC7，TIM8_CH1/CH2 编码器输入 |
| B 输入 | — | PB0 IN1 / TIM3_CH3；PB1 IN2 / TIM3_CH4 |
| A / U6 / CN3 | 1、6 | AO1、AO2 电机两端 |
| A / CN3 | 2、5 | GND、编码器 5V |
| A / CN3 | 3、4 | PB6、PB7，TIM4_CH1/CH2 编码器输入 |
| A 输入 | — | PA6 IN1 / TIM3_CH1；PA7 IN2 / TIM3_CH2 |

手转编码器已确认 A 为左轮、B 为右轮。2026-10-23 架空电机短测后，软件正向设置为 A 的 IN1 主导、B 的 IN2 主导（`CAR_MOTOR_A_FORWARD_IN1=1`，`CAR_MOTOR_B_FORWARD_IN1=0`），与此前标定的前进计数正方向一致。原理图本身不能证明车体安装方向，此配置来自实测。

AT8236 同时支持快衰减和慢衰减 PWM。实车对照中快衰减 35% 未起转，慢衰减相同有效驱动占比能够起转，因此当前默认 `CAR_MOTOR_SLOW_DECAY=1`。正向 IN1 主导时，IN1 常高，IN2 高电平占比为 `1-duty`；IN2 主导时对调。PWM 非驱动阶段两输入高，处于刹车续流状态；零命令仍强制双输入低，滑行/休眠。不能将反相调制输入的占空比误当作有效驱动占比。依据[中科微 AT8236-S409-V1.1 手册](https://datasheet.lcsc.com/datasheet/pdf/d8c76808c9e9a8c1969b3dbfc127e078.pdf)第 5～6 页；没有沿用另一厂商 AT8236-MS 的唤醒时间。

2026-10-25 新增独立 `Board_MotorBrake`，按[原厂手册第 5 页](https://datasheet.lcsc.com/lcsc/2109242230_ZHONGKEWEI-AT8236_C2827823.pdf)将每个电机的两输入均置高，使电机两端同为低电平而制动，不输出反向驱动。四个 CCR 同时更新为 ARR+1；普通零命令仍为双低。控制器只在最终 BRAKING 阶段请求，最长 250 ms；板级同时检查使能与 USER。故障入口仍立即强制双低，完成后释放。高 CCR 在刹车期间不是满功率正向驱动，诊断须结合状态和轨迹 bit2 解读。

## H题新增资源

TIM4 和 TIM8 使用 16 位自动重装 65535，TI1/TI2 双相编码器模式，数字滤波设置为 6；每个控制周期读取计数并计算有符号回绕差值。A 对应 TIM4，B 对应 TIM8，逻辑左/右由 `CAR_LEFT_IS_MOTOR_A` 决定。无须启用编码器中断。编码器供电为接口 5V，接线前确认实际模块输出电平与主板输入要求。

MPU6050 配置 Z 轴 ±500°/s、DLPF 3、1 kHz 输出，主循环约 200 Hz 读取。启用 DATA_RDY 状态（INT_ENABLE=0x01，INT_PIN_CFG=0），每次读取先验证 DATA_RDY，I²C 出错或数据未更新使本次采样无效。软件 I²C 使用 Cortex M3 DWT 计数器，SCL 拉伸等待有界。蜂鸣器使用 PA15，保留 PA13/PA14 的 SWD；默认输出极性需要实物确认。

`.ioc` 记录资源和主要参数，实际初始化仍由板级驱动负责。本次接口审计覆盖新增引脚冲突与编码器模式，但不等同于通过 CubeMX 重新生成代码的验证。

寄存器依据：[InvenSense MPU6050 寄存器手册](https://invensense.tdk.com/wp-content/uploads/2015/02/MPU-6000-Register-Map1.pdf)（[厂商原文镜像](https://arduino.ua/docs/RM-MPU-6000A.pdf)）。
