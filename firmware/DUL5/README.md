# DUL5 实测固件

本目录 BIN/HEX 与本次小车实测镜像一致，面向 STM32F103RCT6 / WHEELTEC C10B；起始地址 `0x08000000`。已包含本车编码器、轮径、灰度与方向配置，移植到另一台车前须重新标定。

- 速度：普通/交叉均 370 mm/s，圈数只选 1 或 4。
- 上电默认普通 1 圈；长按 USER 切路线，双击切圈数，短按开始。
- 实测：普通单圈 11.739 s；交叉四圈 51.695 s；各成功一轮。
- BIN SHA256：`636f75bf43d7da71ebf2e04c508988210de0a4d33f5ef80e615a63ea7606c7df`。

从源码重新构建：`python3 tools/build_firmware.py --dual-mode --toolchain <ARM-GCC-bin目录>`。重编译后的二进制可能因工具链/路径/构建选项而不同；这里保留的是实际上板验证的镜像。
