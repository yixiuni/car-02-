# T321-C2-OLED 当前固件

C2 控制版本本车完成交叉四圈 **29.972 秒**，fault 0、17 次过点，用户反馈效果不错。该包保留相同控制源码和配置，只更新 OLED：大字显示如 `29.972 S`，运行时更新、结束后保留、下次启动清零。已烧录、完整回读及主板帧缓冲核验通过；一次成功不代表长期稳定，OLED 更新后的整车重复性仍待验证。

- BIN 烧录地址 `0x08000000`；HEX 自带地址。
- 上电默认 NORMAL / 1 圈；长按 USER 切路线，双击切 1/4 圈，短按启动。
- 起点为轮轴中点对准 A、车头朝 B；CROSS 会自动转向 C。
- 构建：`python3 tools/build_firmware.py --time-trial-arc-phase --toolchain /path/to/arm-toolchain/bin`。
- 校验和、源码指纹和证据链接见 [manifest](manifest.json)。
- [控制修正、实车成绩与 OLED 验证](../../docs/T321-C2入C右侧纠偏.md)。

灰度接收兼容连续模拟量上报和查询回复。本车标定不应直接用于另一台车。沿用 T321 RAM 布局与魔数，精确区分版本须核对 SHA256。旧版镜像保留于其他固件目录。
